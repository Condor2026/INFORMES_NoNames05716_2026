# Security Policy

## Reporting a Vulnerability

If you identify a false positive, an outdated indicator, or a new IoC related to **NoName057(16)** that is not yet included in this repository:

1. Do **not** open a public issue for sensitive information.
2. Send an email to: **[TU-EMAIL-AQUI]** with the subject line: `[NoName057] IoC Update`.
3. Provide as much context as possible: source, timestamps, and supporting evidence.

## Response

- **Acknowledgment:** Within 24 hours.
- **Validation:** Within 3 business days.
- **Update:** Validated IoCs will be added to the `/iocs` directory and `CHANGELOG.md` updated.

## Scope

This policy covers false positives, new infrastructure, and TTP corrections for NoName057(16) operations.
